# E-commerce Operations & Customer Insights

## Project Overview
This project uses SQL to analyse e-commerce transactions, customer behaviour, sales performance, and delivery operations.

The objective is to answer practical business questions using a relational database and develop SQL skills relevant to Data Analyst interviews.

## Dataset
- **Source:** Brazilian E-Commerce Public Dataset by Olist
- **Format:** CSV files
- **Database:** MySQL

The original dataset source will be credited here: https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Project Objectives
- Analyse sales and order trends.
- Understand customer purchasing behaviour.
- Evaluate product and seller performance.
- Investigate delivery delays and customer reviews.
- Analyse payment patterns.
- Apply SQL techniques to real-world business questions.
